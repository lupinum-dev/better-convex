# Tutorial starter guardrails

This starter is the finished app of the quick start. Its files are the last version of each file in `docs/content/docs/2.get-started/`; `test/unit/tutorial-docs.test.ts` in the repository fails when they differ.

- Change a file here and on its tutorial page together.
- Keep it small: one table, email-code sign-in, an owner check in every Convex function.
- Do not add organizations, MCP, agents or background jobs. The other starters show those.
