Choose by how much integration code you want to write yourself.

- Choose **Better Convex Nuxt** for Nuxt 4 with server-rendered live queries, Better Auth, server calls, mutation state, uploads, and MCP.
- Evaluate **nuxt-convex** when its smaller query and storage API matches your app and you accept its current work-in-progress status.
- Evaluate **convex-nuxt** for its Nuxt 3 and `convex-vue` model, especially if you already use that stack.
- Build it yourself when you need full control of the Convex client.

## Verified versions

This comparison was verified on **July 14, 2026** against released npm artifacts and official project documentation.

| Project            | Compared version | Declared foundation                           |
| ------------------ | ---------------- | --------------------------------------------- |

## Architectural difference

### One integrated module

Better Convex Nuxt handles SSR, hydration, subscriptions, sign-in changes, and cleanup together. Its API is larger and makes more choices for you.

The cost is that you follow its lifecycle and its supported dependency versions.

### Smaller wrapper

`nuxt-convex` exposes a focused SSR query plus file-storage helpers in its `0.0.6` artifact. Its README labels the project work in progress and not ready for production use.

A smaller API is a good choice when you need only those helpers. Your application must handle everything else.

### Nuxt 3 integration

`convex-nuxt` documents real-time queries, SSR/SSG through suspense, and authentication by calling `setAuth` on its Convex client. It is based on `convex-vue` and declares Nuxt 3-era dependencies.

This can fit an existing Nuxt 3 application. It is not a drop-in replacement for the Nuxt 4 and Better Auth setup described here.

### Manual integration

A manual integration gives full control over the client, auth, server calls, and lifecycle. Your application must then handle hydration, user switches, cleanup, error handling, and upgrades.

Choose it when your product needs behavior that a shared module cannot provide.
