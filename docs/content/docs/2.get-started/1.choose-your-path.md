Pick the path that matches your application.

## New Nuxt app

Follow the quick start in order:

1. [Install the module](/docs/get-started/installation).
2. [Build a live page](/docs/get-started/first-realtime-page).
3. [Add a mutation](/docs/get-started/add-a-mutation).
4. [Add authentication](/docs/get-started/add-authentication).
5. [Protect data and routes](/docs/get-started/protect-data).
6. [Next steps](/docs/get-started/next-steps).

Steps 1 to 3 do not use authentication. Stop after step 3 if your app has no sign-in.

## Existing Nuxt and Convex app

Start with [installation](/docs/get-started/installation). Then move one page at a time to the module composables.

Remove your old Convex client plugin when the last page uses the module. Do not run two Convex clients side by side. They create duplicate subscriptions and conflicting auth state.

## Plain Vue or Vite

Use [`@lupinum/better-convex-vue`](/docs/get-started/plain-vue) when you do not use Nuxt. It has the same browser composables. It has no server rendering, server routes, or Better Auth setup.

## ChatGPT and Claude through MCP

Complete the Nuxt quick start with authentication first. Then follow:

1. [Add MCP to your application](/docs/build/agents/mcp-application).
2. [Connect ChatGPT and Claude](/docs/build/agents/connect-chatgpt-and-claude).
3. Optional: show a card for a tool with [MCP Apps](/docs/build/agents/mcp-apps).

## Use a coding agent

A coding agent is a development tool that can inspect and change your project.
Every Better Convex package contains documentation for coding agents that
matches the installed version: `dist/agent/AGENTS.md`, also exported as
`<package>/agent-docs`. It starts with a task index and the rules that agents
most often get wrong.

Add this pointer to your project's `AGENTS.md` (or `CLAUDE.md`). Name the
package that you installed:

```md [AGENTS.md]
## Better Convex

Before you change Convex functions or Better Convex code, read
`node_modules/@lupinum/better-convex-nuxt/dist/agent/AGENTS.md` and follow its
"Start here" table. It matches the installed version. Prefer it over the
website and over knowledge of earlier versions.
```

To add Better Convex to an application, give your agent this prompt:

```text
Add Better Convex to this application. Install @lupinum/better-convex-nuxt@next
(or @lupinum/better-convex-vue@next for Vue without Nuxt). Then read
node_modules/<package>/dist/agent/AGENTS.md and follow its "Start here" table.
Add the Better Convex pointer from the package README to AGENTS.md. Finish
with the "Check your setup" steps of the Installation page.
```

The pointer names the installed package, so an upgrade or a rollback selects
the matching documentation. Installing a package never changes your project
instructions.

## Start from an example

The repository has four starters. Start with `public` or `mcp-oauth-agent`:

- `starters/public`: a public live todo app without sign-in.
- `starters/mcp-oauth-agent`: Better Auth, OAuth, and MCP together.
- `starters/team`: a team app with the Better Auth organization plugin, roles,
  and teams. Use it as the reference for organization access rules.
- `starters/agency`: an app that manages client workspaces and stores the
  access rules in its own Convex tables.
