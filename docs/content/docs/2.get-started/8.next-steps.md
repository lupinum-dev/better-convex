Your app now renders live Convex data, writes data, signs users in, and checks the user in Convex. Pick the next task.

## Connect ChatGPT or Claude

Let an AI assistant call your Convex functions as a signed-in user, through MCP. Follow these pages in order:

1. [Add MCP to your application](/docs/build/agents/mcp-application): install `@lupinum/better-convex-agents`, add the OAuth settings, and define one tool.
2. [Connect ChatGPT and Claude](/docs/build/agents/connect-chatgpt-and-claude): create a client for each host, connect it, and test it with MCP Inspector.
3. Optional: [MCP Apps](/docs/build/agents/mcp-apps) shows a card for a tool result.

[MCP on Convex](/docs/build/agents/mcp) explains how the pieces fit together.
