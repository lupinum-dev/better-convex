Better Convex connects Nuxt to Convex. Pages render Convex data on the server and then stay live in the browser. It also adds Better Auth sign-in and optional MCP tools for ChatGPT and Claude.

## Start here

Follow the quick start in order. Each page builds on the previous one.

1. [Install the module](/docs/get-started/installation)
2. [Build a live page](/docs/get-started/first-realtime-page)
3. [Add a mutation](/docs/get-started/add-a-mutation)
4. [Add authentication](/docs/get-started/add-authentication)
5. [Protect data and routes](/docs/get-started/protect-data)
6. [Next steps](/docs/get-started/next-steps), including MCP and deployment

Not sure this library fits? Read the [introduction](/docs/overview/introduction) and the [limitations](/docs/overview/limitations). Using Vue without Nuxt? Go to [plain Vue and Vite](/docs/get-started/plain-vue).
