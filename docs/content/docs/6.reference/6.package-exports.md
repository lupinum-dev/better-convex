## Application-facing entries

| Import                                           | Purpose                                                        |
| ------------------------------------------------ | -------------------------------------------------------------- |
| `@lupinum/better-convex-nuxt`                    | Nuxt module and ordinary root types                            |
| `@lupinum/better-convex-nuxt/better-auth/client` | Advanced Better Auth client definition and inference types     |
| `@lupinum/better-convex-nuxt/better-auth/server` | Convex-side Better Auth integration and user projection helper |
| `@lupinum/better-convex-nuxt/errors`             | Framework-free call error contract, codes, and guards          |
| `@lupinum/better-convex-nuxt/test`               | Deterministic typed component-test runtime                     |
| `@lupinum/better-convex-nuxt/server`             | Server caller, request user helpers, and H3 error mapping      |

The package also publishes generated Convex component/configuration paths used by codegen and
testing. The generated [API surface](/docs/reference/api-surface) is the single exact inventory.
Do not deep-import `dist`, `src/runtime`, or build-directory files.

## Vue entries

| `@lupinum/better-convex-vue`          | Beta   | Vue plugin plus query, pagination, mutation, action, form, file upload, and connection state |

The embedded entry does not expose credentials or a raw replaceable Convex client.

## MCP entry

`@lupinum/better-convex-mcp` is an experimental, provider-neutral resource-server
package. Its current beta exposes the bounded Convex HTTP handler, verifier
contracts, safe access context, and sanitized tool-result helper. It does not
depend on Nuxt or Better Auth, auto-export Convex functions, or own application
authorization.

## Nuxt aliases

| Alias            | Target                                      |
| ---------------- | ------------------------------------------- |
| `#convex/api`    | Consumer `convex/_generated/api`            |
| `#convex/server` | Published Better Convex Nuxt server surface |

Use `#convex/api` in components, composables, middleware, and Nitro handlers. Convex code under `convex/` uses its relative generated imports instead.

## Auto-imports

The module auto-imports the documented core composables into Nuxt application code. It
auto-imports the request-bound `serverConvex`, `getConvexUser`, `requireConvexUser`, and
`toConvexH3Error` into Nitro server code. Auth-enabled builds additionally auto-import
`useConvexAuth` and the auth route middleware. No auth facade or global auth components exist in a
Convex-only build. Without auth, `getConvexUser` returns `null` and `requireConvexUser` throws 401.

## Root types

The root exports ordinary types for module options, auth status/options, runtime configuration, the client handle, and the composables:

- return types: `UseConvexQueryState`, `UseConvexPaginatedQueryState`, `UseConvexMutationReturn`, `UseConvexActionReturn`, `UseConvexFormReturn`, `UseConvexFileUploadReturn`, `UseConvexConnectionStateReturn`, and `UseConvexAuthReturn`;
- Nuxt query options: `UseNuxtConvexQueryOptions` and `UseNuxtConvexPaginatedQueryOptions`, which add `server` and `lazy` to the Vue options;
- argument and item helpers: `UseConvexQueryParameters`, `ConvexQueryArgs`, `PaginatedQueryArgs`, and `PaginatedQueryItem`;
- the query gate reason: `ConvexQueryBlockedBy` (`'skip' | 'auth' | 'manual' | null`);
- the user and error shapes: `ConvexUser`, `ConvexCallError`, and `ConvexCallErrorCode`.

Types shared with `@lupinum/better-convex-vue` are re-exported unchanged, so one name has one meaning in both packages. `UseConvexQueryOptions` and `UseConvexPaginatedQueryOptions` are the plain Vue option types; import them from `@lupinum/better-convex-vue`. Pass `UseNuxtConvexQueryOptions` as the second type argument of `UseConvexQueryParameters` to describe the Nuxt options. Advanced auth-client inference, error guards, and server-only options live on their dedicated subpaths.

Runtime values other than the default Nuxt module live in their dedicated entries or Nuxt auto-import surface.

## Missing generated API

Before Convex codegen creates `convex/_generated/api`, `#convex/api` points to a diagnostic placeholder. Accessing a function produces a codegen-oriented error instead of an untyped fallback.

See the generated [API surface](/docs/reference/api-surface) for the exact current inventory.
