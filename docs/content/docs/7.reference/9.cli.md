The module installs the `better-convex` command. Run it with `pnpm exec better-convex`.

```bash
better-convex init [--typed-client] [--yes] [--site-url <origin>]
better-convex convex <command> [options]
better-convex auth schema --config <schema-options.ts> [options]
better-convex --version
```

## `init`

`init` sets up authentication for a development deployment. It writes the auth files, generates the auth schema, and sets the development secrets and the first signing key. See [add authentication](/docs/get-started/add-authentication) for each step.

| Option                | Effect                                                                        |
| --------------------- | ----------------------------------------------------------------------------- |
| `--typed-client`      | Also write `app/convex-auth.ts`                                               |
| `--yes`, `-y`         | Do every step without asking. Use it in scripts and CI.                       |
| `--site-url <origin>` | The development site URL. Without it, the default is `http://localhost:3000`. |

`init` refuses a production deployment, also with `--yes`. It stops without changes when a file exists with other content. Running it again is safe.

Without `--yes`, `init` reads each answer from standard input, so you can also pipe answers:

```bash
printf 'y\ny\n\ny\n' | pnpm exec better-convex init
```

## `convex`

`convex` runs the Convex CLI that is installed in the project. It reads the deployment only from `.env.local` and removes every other Convex setting from the environment, so a command cannot reach another deployment by accident.

| Command                               | Deployment                                       |
| ------------------------------------- | ------------------------------------------------ |
| `convex dev`                          | A development, local, or anonymous deployment    |
| `convex dev --anonymous`              | A new anonymous local deployment                 |
| `convex deploy`                       | A production deploy key or a self-hosted backend |
| `convex codegen`, `env`, `run`        | The deployment in `.env.local`                   |
| `convex logs`, `convex data`          | The deployment in `.env.local`                   |
| `convex configure`                    | Choose a deployment interactively                |
| `convex deployment select <selector>` | Choose a deployment by name                      |

Other options pass through to the Convex CLI. Options that choose a different deployment, such as `--prod`, `--url`, or `--deployment`, fail before the Convex CLI starts.

```bash
pnpm exec better-convex convex logs --history 20
pnpm exec better-convex convex data messages --limit 10
```

## `auth schema`

`auth schema` generates `convex/betterAuth/schema.ts` and `schemaMetadata.ts` from your Better Auth plugin list. `init` runs it for you. Run it again after you change `convex/betterAuth/schemaPlugins.ts`. See [Better Auth plugins](/docs/build/authentication/better-auth-plugins).
